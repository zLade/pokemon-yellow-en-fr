# Données de provenance

Ce dossier ne contient aucune ROM. Il fixe les empreintes des entrées attendues et des livrables français. Les extractions Unicode chinoises épinglées restent, pour compatibilité avec les outils existants, sous `build/chinese-english-fidelity/extraction/`.

HZK16 n'est pas présent dans le dépôt : aucune nouvelle extraction HZK16 ne doit être revendiquée. `chinese_records.csv` et `chinese_glyph_map.csv` sont les sources Unicode immuables.

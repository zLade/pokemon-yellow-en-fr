# Pokémon Yellow NES — English & French

English and French translations of **Lei Dian Huang Bi Ka Qiu Chuan Shuo
(NJ046)**, an unofficial Famicom game using mapper 163. Based on the work of
the ROM-hacking community, with in-game credits to LUIGA2009, ZLADE and CHPEXO.

## Downloads

| Version | Patch and instructions | Source code |
|---|---|---|
| English 2.0.3 | [English release](https://github.com/zLade/pokemon-yellow-en-fr/releases/tag/en-v2.0.3) | [en branch](https://github.com/zLade/pokemon-yellow-en-fr/tree/en) |
| French 2.0.12 | [French release](https://github.com/zLade/pokemon-yellow-en-fr/releases/tag/fr-v2.0.12) | [fr branch](https://github.com/zLade/pokemon-yellow-en-fr/tree/fr) |

Releases contain IPS patches, instructions and checksums. No complete ROM is
distributed. Both current patches apply directly to a clean copy of the
original Chinese NES ROM:

- Filename: `Lei Dian Huang Bi Ka Qiu Chuan Shuo (NJ046) (Ch) [!].nes`
- Size: **2,097,168 bytes**
- SHA-256: `450d40c0d648f8651ac6b42f1c094921cb2202ed420194e65271e2f7b40c65ed`

Choose one language and apply its IPS to a separate clean copy. Do not stack
the patches or use an English translation, an already patched ROM, or the
Game Boy game. IPS does not verify the source identity: check its hash first,
then check the resulting ROM against the selected release's instructions.
The 2015 English ROM is an internal build reference, not the input for these
published patches.

# Pokémon Yellow NJ046 — English Fidelity 2.0.1

This directory contains one IPS patch only. No complete ROM is distributed.

This release includes the completed English source review, natural battle and
move-learning messages, two-line graphical labels for long official move
names, the finalized `YELLOW VERSION` title and the verified interactive
move-forgetting cursor.

Apply `Pokemon_Yellow_NJ046_EN_v2.0.1.ips` to a clean copy of `yellow.nes`:

- base size: `2,097,168` bytes;
- base SHA-256: `69520103102677b33b47c15fae804dc1a742347a9ee1b02a9195e795eb6e431b`;
- mapper: iNES mapper 163.

Resulting ROM:

- SHA-256: `0d9150ab4cc7281ee9c449d6fc0d0c813ed1d3d5c2c5312a6791c8e66acd7483`.

Two independent project IPS implementations rebuilt the certified ROM byte
for byte. Final gates include the 1,912/1,912 pointer manifest, the 101/101
dynamic layout matrix and targeted Mesen scenarios.

Verify the downloaded patch against `SHA256SUMS` before applying it.

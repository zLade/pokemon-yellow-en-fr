# Pokémon Jaune NJ046 — Français 2.0.9

Ce dossier contient uniquement le patch IPS. Aucune ROM commerciale n'est
distribuée.

Cette révision remplace l'abréviation `FUI` par le libellé officiel complet
`Fuite`. La zone de tuiles dynamiques du menu de combat commence désormais à
`$0920` au lieu de `$0960`, ce qui réserve les 18 glyphes nécessaires à
`ATQ.`, `Objet`, `PKMN` et `Fuite` sans chevaucher le message de gauche.

ROM cible après application :

- SHA-256 : `dbdff69c01fc772b94288c465e5082b0bf17038c50e26a66ec33081c5387f7d8`
- mapper : iNES mapper 163

Appliquer `Pokemon_Jaune_FR_v2.0.9.ips` à `yellow.nes`, dont le SHA-256 est
`69520103102677b33b47c15fae804dc1a742347a9ee1b02a9195e795eb6e431b`.

Contrôler le fichier téléchargé avec `SHA256SUMS` avant de l'appliquer.

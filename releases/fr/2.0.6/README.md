# Pokémon Jaune NJ046 — Français 2.0.6

Ce dossier contient uniquement le patch IPS. Aucune ROM commerciale n'est
distribuée.

Cette révision élargit le nom `Sacha` de 16 à 24 pixels sur la fiche joueur.
Une tuile blanche dupliquée est recyclée sans modifier son rendu d'origine,
ce qui permet des lettres plus larges et mieux espacées. Le portrait, le décor
et les palettes restent inchangés.

ROM cible après application :

- SHA-256 : `2ee48b54d8e7895c717c92a243a8eedf7cdbf8d2fd22e82584ed01d925e68af2`
- mapper : iNES mapper 163

Appliquer `Pokemon_Jaune_FR_v2.0.6.ips` à `yellow.nes`, dont le SHA-256 est
`69520103102677b33b47c15fae804dc1a742347a9ee1b02a9195e795eb6e431b`.

Contrôler le fichier téléchargé avec `SHA256SUMS` avant de l'appliquer.

# Pokémon Jaune NJ046 — Français 2.0.4

Ce dossier contient uniquement le patch IPS. Aucune ROM commerciale n'est
distribuée.

Cette révision corrige la fiche joueur de la 2.0.3 :

- `Ash` devient `Sacha` dans son emplacement d'origine ;
- le portrait du joueur est restauré octet pour octet ;
- aucune tuile partagée avec le portrait ou le décor n'est réutilisée ;
- les palettes originales et toutes les corrections de la 2.0.3 sont
  conservées.

ROM cible après application :

- SHA-256 : `31adbe7076815a6a0f474d63b08cf9451514a955258e4f5523a50794ccedc569`
- mapper : iNES mapper 163

Appliquer `Pokemon_Jaune_FR_v2.0.4.ips` à `yellow.nes`, dont le SHA-256 est
`69520103102677b33b47c15fae804dc1a742347a9ee1b02a9195e795eb6e431b`.

Contrôler le fichier téléchargé avec `SHA256SUMS` avant de l'appliquer.

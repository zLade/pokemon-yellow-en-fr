# Pokémon Jaune NJ046 — Français 2.0.10

Ce dossier contient uniquement le patch IPS. Aucune ROM complète n'est
distribuée.

Cette release regroupe la relecture française complète, les corrections de
syntaxe et de dialogues, les messages de combat naturels, les libellés
d'attaques sur deux lignes, les menus français finalisés et le curseur réel de
l'écran d'oubli d'attaque.

Appliquer `Pokemon_Jaune_FR_v2.0.10.ips` à une copie propre de `yellow.nes` :

- taille de la base : `2 097 168` octets ;
- SHA-256 de la base : `69520103102677b33b47c15fae804dc1a742347a9ee1b02a9195e795eb6e431b` ;
- mapper : iNES mapper 163.

ROM obtenue après application :

- SHA-256 : `f292c39ebc0b6c4e55ae1d39a6fc4417b0b9823a96667b4f7bae6294d9a334b1`.

Le patch a été reconstruit avec deux implémentations IPS et comparé octet par
octet à la ROM certifiée. Contrôles finaux : manifeste 1 916/1 916, matrice
dynamique 101/101 et scénarios Mesen ciblés PASS.

Contrôler le fichier téléchargé avec `SHA256SUMS` avant de l'appliquer.

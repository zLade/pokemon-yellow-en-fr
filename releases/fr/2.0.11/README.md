# Pokémon Jaune NJ046 — Français 2.0.11

Release française actuelle. Ce dossier distribue uniquement le patch IPS ; aucune ROM complète n'est suivie par Git.

La version 2.0.11 reprend intégralement la traduction certifiée 2.0.10 et ajoute la correction de la table de hauteur musicale NES.

Appliquer `Pokemon_Jaune_NJ046_FR_v2.0.11.ips` à une copie propre de `yellow.nes` :

- taille : `2 097 168` octets ;
- SHA-256 : `69520103102677b33b47c15fae804dc1a742347a9ee1b02a9195e795eb6e431b` ;
- mapper : iNES mapper 163.

ROM obtenue : SHA-256 `efc7ba0837a65d06e0658348d3debaa1194b9cf03b59492a1a8d4dfab346327e`.

Contrôles : IPS reconstruit par deux implémentations, changement limité aux 69 octets musicaux attendus, 1 916/1 916 pointeurs, contrat mapper 163 préservé et démarrage Mesen 2.2.1 Dendy PASS.

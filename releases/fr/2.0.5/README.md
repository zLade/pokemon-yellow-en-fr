# Pokémon Jaune NJ046 — Français 2.0.5

Ce dossier contient uniquement le patch IPS. Aucune ROM commerciale n'est
distribuée.

Cette révision agrandit le nom `Sacha` sur la fiche joueur : la police passe
de 5 à 7 pixels de haut tout en restant dans les quatre tuiles originales de
`Ash`. Le portrait, le décor et les palettes de la version originale restent
inchangés.

ROM cible après application :

- SHA-256 : `0a4dc25a42ebc432fccbdb66bd4f4e66b1b758fb85aab1ae1b78f33b576265e6`
- mapper : iNES mapper 163

Appliquer `Pokemon_Jaune_FR_v2.0.5.ips` à `yellow.nes`, dont le SHA-256 est
`69520103102677b33b47c15fae804dc1a742347a9ee1b02a9195e795eb6e431b`.

Contrôler le fichier téléchargé avec `SHA256SUMS` avant de l'appliquer.

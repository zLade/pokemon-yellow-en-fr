# Pokémon Jaune NJ046 — Français 2.0.3

Ce dossier contient uniquement le patch IPS. Aucune ROM commerciale n'est
distribuée.

Cette révision corrige la fiche joueur et l'écran de sauvegarde de la 2.0.2 :

- le nom graphique `Ash` devient `SACHA` sur la fiche joueur ;
- les libellés français réutilisent les indices de fond, de trait et d'ombre
  propres à chaque écran ;
- les 32 octets de palette observés dans Mesen restent strictement identiques
  à ceux de la ROM d'origine.

Elle conserve également les traductions `NOM`, `ARGENT`, `POKÉDEX`,
`SAUVEGARDE...`, ainsi que les corrections d'effacement de la 2.0.2.

ROM cible après application :

- SHA-256 : `a0e328748af46acd14bd4e67f5682be6894f07e9661fec5230ccd0c3a85ec859`
- mapper : iNES mapper 163

Appliquer `Pokemon_Jaune_FR_v2.0.3.ips` à `yellow.nes`, dont le SHA-256 est
`69520103102677b33b47c15fae804dc1a742347a9ee1b02a9195e795eb6e431b`.

Contrôler le fichier téléchargé avec `SHA256SUMS` avant de l'appliquer.

# Pokémon Jaune NJ046 — Français 2.0.8

Ce dossier contient uniquement le patch IPS. Aucune ROM commerciale n'est
distribuée.

Cette révision harmonise les 177 noms d'attaques et 121 textes ou libellés de
combat. Les capacités de première génération reprennent leur nom français
officiel de Pokémon Rouge/Bleu lorsqu'il tient dans les dix cases du menu NES ;
les noms plus longs sont raccourcis de façon cohérente. Les phrases dynamiques
et les menus ont également été corrigés, notamment `Régis envoie Évoli`,
`Pikachu utilise Éclair`, `ATQ.`, `Objet`, `PKMN` et `FUI`.

ROM cible après application :

- SHA-256 : `8c8d9d07a569d321b50b28c35018111114917ad2f1cf7993d6a16cf2ac828b51`
- mapper : iNES mapper 163

Appliquer `Pokemon_Jaune_FR_v2.0.8.ips` à `yellow.nes`, dont le SHA-256 est
`69520103102677b33b47c15fae804dc1a742347a9ee1b02a9195e795eb6e431b`.

Contrôler le fichier téléchargé avec `SHA256SUMS` avant de l'appliquer.

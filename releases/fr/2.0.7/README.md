# Pokémon Jaune NJ046 — Français 2.0.7

Ce dossier contient uniquement le patch IPS. Aucune ROM commerciale n'est
distribuée.

Cette révision redessine le `S` de `Sacha` avec une forme arrondie et
symétrique, plus proche de la police graphique du jeu. Elle conserve la zone
élargie à 24 pixels de la 2.0.6, ainsi que le portrait, le décor et les
palettes d'origine.

ROM cible après application :

- SHA-256 : `0ed4d83d0accd2a58d23f18e3a681cefe334183109d40ebd6073e5f5b3dff5e0`
- mapper : iNES mapper 163

Appliquer `Pokemon_Jaune_FR_v2.0.7.ips` à `yellow.nes`, dont le SHA-256 est
`69520103102677b33b47c15fae804dc1a742347a9ee1b02a9195e795eb6e431b`.

Contrôler le fichier téléchargé avec `SHA256SUMS` avant de l'appliquer.

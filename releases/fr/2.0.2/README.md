# Pokémon Jaune NJ046 — Français 2.0.2

Ce dossier contient uniquement le patch IPS. Aucune ROM commerciale n'est
distribuée.

Cette révision complète la traduction des menus secondaires :

- `NAME`, `MONEY` et `POKEDEX` deviennent `NOM`, `ARGENT` et `POKÉDEX` ;
- `SAVING...` devient `SAUVEGARDE...` ;
- les messages trop longs `Pas de Pokémon` et `Pas en stock!` sont remplacés
  par `Pas de PKMN` et `Indisponible`, afin que leur effacement soit complet.

ROM cible après application :

- SHA-256 : `a9ed488244a000366df9338e1b7a641d014471c41961a2938bee62bc806c7d4a`
- mapper : iNES mapper 163
- titre : vrai logo anglais `YELLOW VERSION`, menus français et petit libellé
  inférieur `JAUNE`

Appliquer `Pokemon_Jaune_FR_v2.0.2.ips` à `yellow.nes`, dont le SHA-256 est
`69520103102677b33b47c15fae804dc1a742347a9ee1b02a9195e795eb6e431b`.

Contrôler le fichier téléchargé avec `SHA256SUMS` avant de l'appliquer.
